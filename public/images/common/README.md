# COMMON Image Assets

- `home/`: 홈 이미지
- `spaces/`: COMMON SPACE 실제 공간 사진
- `programs/`: 이번 주 COMMON 및 프로그램 사진
- `tables/`: 카페, QUIET TABLE, COMMON TABLE 사진
- `connect/`: COMMON CONNECT 관련 이미지
- `impact/`: 지역사회 활동 및 COMMON CIRCLE 사진
- `brand/`: COMMON 브랜드 asset

실제 사진 파일명은 영문 소문자와 hyphen(`-`)을 기본으로 사용합니다.

예:

- `room-a-01.jpg`
- `common-table-01.jpg`
